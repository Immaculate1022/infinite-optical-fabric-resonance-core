## Quick Start

### Python (Kuramoto + 5-cube)
```bash
git clone https://github.com/Immaculate1022/infinite-optical-fabric-resonance-core.git
cd infinite-optical-fabric-resonance-core
pip install -r requirements.txt
python examples/run_resonance.py
```

### JavaScript FluxEngine + Server
```bash
cd software/iof-v3
npm install
node server.js          # WebSocket on ws://localhost:8765
```

### Topological Peak Ascent
```bash
cd software/topographic-ascent
# See README.md for usage of TopologicalMemoryBank and reasonWithMemory
```
