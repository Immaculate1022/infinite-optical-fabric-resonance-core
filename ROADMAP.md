# IOF Resonance Core — Roadmap

This project is intentionally kept alive and strengthened over time.

## Current Status (v0.1.0)

- [x] 5D penteract graph generation (32 nodes / 80 edges)
- [x] φ-scaled Kuramoto oscillator network
- [x] Order parameter & coherence metrics
- [x] Runnable example + basic tests
- [x] Mathematical formalization notes
- [x] CC BY 4.0 open license

## Near-term (v0.2)

- [ ] Interactive Jupyter notebook with live order-parameter plots
- [ ] Optional delay-coupled (photonic-inspired) Kuramoto variant
- [ ] Visualization of the 5-cube embedding / projections
- [ ] Parameter sweep tools (K vs mean R curves)
- [ ] Unit tests expanded + CI via GitHub Actions

## Medium-term

- [ ] Discrete-time / map version suitable for digital photonic simulation
- [ ] Multi-layer “jellyfish mesh” clustering model (F₅ motif)
- [ ] Simple optical-path loss model on the edges
- [ ] Export to common graph formats (GraphML, GEXF)

## Longer-term / Community

- Hardware feasibility sketches (silicon photonics, free-space, fiber)
- Educational modules / lecture notes
- Connections to other high-dimensional synchronization literature
- Alternative topologies (other polytopes, small-world hybrids)

Contributions that advance any of these items are warmly welcomed.

The goal remains: keep the fabric open, useful, and growing so that anyone can explore and build upon it.
