# Contributing to Infinite Optical Fabric (IOF) Resonance Core

Thank you for your interest in contributing!

This project is intentionally open so that the ideas can spread freely.

## How to contribute

1. Fork the repository
2. Create a feature branch
3. Make your changes (new simulations, diagrams, math formalizations, hardware mappings, etc.)
4. Open a Pull Request with a clear description

## Ideas welcome

- Mathematical formalization of the φ-scaled Kuramoto network
- Simulation code (Python, Julia, MATLAB, etc.)
- Improved or alternative visualizations (SVG preferred for openness)
- Photonic hardware feasibility notes
- 4D/5D projection algorithms for the penteract
- Educational materials

All contributions will be licensed under the same **CC BY 4.0** terms so the work remains free for everyone.

## Code of Conduct

Be kind, be constructive, and keep the light flowing.
